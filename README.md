# Singleton 패턴 실습 (11주차)

## 환경
- 언어: Python 3.12.4
- 실행 방법: 터미널에서 `python main.py`

## 실행 결과
```
== 동일 인스턴스 비교 ==
a is b : True
id(a) = 1858388602768
id(b) = 1858388602768

== 상태 공유 확인 ==
a.counter = 10 으로 변경
b.counter = 10
```

## 설명
1. 인스턴스는 어디에 저장되나요?

인스턴스는 Singleton 클래스 안에 있는 `_instance`라는 클래스 변수에 저장됩니다. 클래스 변수는 객체마다 따로 만들어지는 것이 아니라 클래스 자체에 하나만 존재합니다. 처음에는 None으로 되어 있다가 객체가 처음 생성되면 해당 인스턴스를 저장하는 역할을 합니다.

2. 반복 요청해도 새 객체가 안 만들어지는 이유는?

Singleton()을 호출하면 `__new__` 메서드가 실행됩니다. 처음 호출했을 때는 `_instance`가 None이기 때문에 새로운 객체를 생성해서 저장합니다. 하지만 두 번째 호출부터는 이미 `_instance`에 객체가 저장되어 있기 때문에 새로운 객체를 만들지 않고 기존 객체를 그대로 반환합니다.

3. 두 변수가 하나의 인스턴스를 공유한다는 근거는?

실행 결과를 보면 세 가지로 확인할 수 있습니다. 먼저 a is b의 결과가 True로 나와 두 변수가 같은 객체라는 것을 알 수 있습니다. 또 id(a)와 id(b)의 값도 동일하게 나왔습니다. 마지막으로 a.counter의 값을 10으로 변경한 뒤 b.counter를 확인했을 때도 10으로 출력되었습니다. 이를 통해 두 변수가 별개의 객체가 아니라 하나의 객체를 함께 사용하고 있다는 것을 확인할 수 있었습니다.
